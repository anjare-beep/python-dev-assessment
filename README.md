# Python Developer Assessment

## Project Overview

This repository contains solutions for a Python Developer Assessment. The project covers Python fundamentals, Git and GitHub, code style and linting, data structures and algorithms, object-oriented programming, error handling, debugging, and API interaction.

## Tasks Completed

* hello.py – Hello World task
* bad_style.py – Code formatting and linting with Black and Flake8
* dsa_challenges.py – Data structures and algorithm challenges
* book_store.py – Object-oriented programming (Book class)
* debug_errors.py – Error handling and debugging exercises
* api_client.py – API interaction using the requests library

## Running the Code

Run any file from the project folder:

python hello.py
python dsa_challenges.py
python book_store.py
python debug_errors.py
python api_client.py
